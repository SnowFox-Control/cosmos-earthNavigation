# 二维极坐标火箭上升数值环境

> 本文保留建模过程和历史接口说明。文件已分类整理，当前运行方法与配置入口以根目录 README.md 和本目录《参数调整指南.md》为准；所有输出现存于 results/ 子目录。

在 MATLAB 中将当前目录设为本文件所在文件夹，运行 `demo_rocket`。
仅使用基础 MATLAB（图像导出使用 R2020a 起提供的 exportgraphics）。
运行 `verify_rocket` 执行物理一致性和数值精度检查。

## 模型与控制定义

采用不随地球旋转的地心平面极坐标，忽略地球自转、风、升力和姿态动力学；空气静止。
状态为 `y=[r,theta,u,w,m,I]`，其中 `u=dr/dt`，`w=r*dtheta/dt`，`I` 是发动机标量总冲量。
所有内部变量使用 SI 单位，角度使用弧度。

控制项为相对速度方向的推力偏角 `delta(t)` 和推进剂排出速率 `q(t)>=0`。
定义 `beta=atan2(w,u)`，则推力相对径向向外的角度 `alpha=beta+delta`。
静止时约定 `beta=0`。飞行路径角相对当地水平为 `gamma=atan2(u,w)`。
起飞前 `p.turnStart=5` 秒强制偏角为零，避免零速度附近转向参考方向的奇异性；之后执行偏角控制节点。
在默认径向初始速度条件下，这对应前 5 秒竖直上升。优化时这段的偏角节点应固定为零，减少无效自由度。

令 `V=sqrt(u^2+w^2)`，`k=0.5*rho0*exp(-h/H)*Cd*A`，`T=c*q`，则

```text
dr/dt     = u
dtheta/dt = w/r
du/dt     = w^2/r + T*cos(alpha)/m - mu/r^2 - k*V*u/m
dw/dt     = -u*w/r + T*sin(alpha)/m - k*V*w/m
dm/dt     = -q
dI/dt     = T
```

严格重力转弯阶段取 `delta=0`，此时推力沿速度方向，轨迹在重力作用下自然弯曲。
如果初始切向速度为零且始终 delta=0，轨迹会保持径向；默认示例先施加短暂的 2 度偏角，再归零。
主动偏转阶段仍忽略升力，属于点质量简化模型。这里控制的是推力方向，未建模姿态执行机构。
因此所谓“重力转弯控制”是初始化转弯及调整推力偏角，不是把重力或轨迹角本身指定为独立控制。

## 文件与运行结果

- `rocket_config.m`：地球、火箭、大气、求解器及控制节点参数。
- `rocket_simulate.m`：ode45 求解、燃尽/落地事件、结果后处理。
- `demo_rocket.m`：示例、六幅诊断图，生成 rocket_demo.png 和 rocket_result.mat。
- `rocket_design.m`：后续优化的前向计算入口。
- `verify_rocket.m`：理想火箭公式、冲量质量关系、径向对称性、真空守恒、落地事件、步长细化验证。

默认参数仅用于教学演示，不对应真实火箭。发射初始高度为 1 m、速度为零，避免在地面事件零点启动。
控制节点之间线性插值，末节点以后保持末值；燃料耗尽后强制关机并进入滑行段。
到达干质量时用事件定位燃尽，重启 ODE，质量和冲量在滑行段保持不变；接触地面时终止。
如果 tf 前没有燃尽，burnoutTime 为 NaN。落地提前终止与到达 tf 应在优化时区别处理。
输出的发动机冲量为 integral(T dt)，不是火箭自身动量变化，也不是固定惯性方向的矢量冲量。

## 后续优化接口

固定时间节点，将两项控制节点值拼成设计向量：

```matlab
[p,control] = rocket_config();
z0 = [control.delta, control.q];
n = numel(control.t);
lb = [-p.deltaMax*ones(1,n), zeros(1,n)];
ub = [ p.deltaMax*ones(1,n), p.qMax*ones(1,n)];
[metrics,out] = rocket_design(z0,p,control.t);
```

`metrics` 返回终点高度、速度分量、推进剂用量、总冲量、采样峰值动压、燃尽时间及落地标记。
确定目标高度/速度、优化终点（燃尽或固定时间）、动压限值后，可定义目标函数和非线性约束。
当前不预设优化目标，也不调用优化工具箱。采样动压峰值不是连续时间约束的严格证明，优化定稿时需要加密检查。
若需要改变有效排气速度模型，应同步修改推力计算和校验；当前 c 为常数，T 与 q 不能独立指定。

## 160 km 圆轨道优化（新增）

原始示例参数保持不变；入轨参数单独存于 `rocket_orbit_config.m`：
初始质量 60000 kg、干质量 6000 kg、有效排气速度 4500 m/s（比冲 458.872 s）。
目标是地表以上 160 km，即地心半径 6531 km，圆轨道速度 7812.302 m/s。

按用户指定的两段燃烧启发结构运行：

```matlab
result = rocket_two_burn_ga;
verify_orbit;
```

需要 Global Optimization Toolbox (`ga`) 和 Optimization Toolbox (`fmincon`)。
第一段亚轨道燃烧、零流率滑行、第二段圆轨化燃烧分别参数化；关闭和启动使用 0.5 秒线性过渡。
10 个变量包括第一段的三个推力偏角、第二段的起止推力偏角、两段流率、两段燃烧时长及滑行时长。
推力偏角约束为 ±10 度，第一转向节点为 0–10 度；流率上限为 350 kg/s，消耗不能超过 54000 kg。
同一发动机重启属于此教学模型的假设，未建模启动损耗、姿态速率、载荷和热约束。

以两段燃烧轨迹生成一半初始种群，其余随机初始化。遗传算法种群 96，运行 180 代，随机种子 161。
设计变量统一缩放到 [0,1]。目标函数为

```text
J = ((h_end - 160000)/10000)^2 + (u_end/1000)^2
    + ((w_end - sqrt(mu/(Re+160000)))/1000)^2
```

超过燃料预算或中途落地的个体被惩罚。此处目标是终端入轨可行性，不是最小燃料，也不声称得到全局最优。
GA 结束后以其最佳个体为初值，使用 SQP 做终端残差修正；最终高精度结果应明确标为“GA + SQP”，不能称为纯 GA 结果。
`rocket_two_burn_ga_stage.mat` 单独保存纯 GA 的残差、种群及迭代曲线。

最终结果在 `rocket_two_burn_result.mat`，并同步写入 `rocket_orbit_final.mat` 供验证器读取。
控制节点导出到 `rocket_orbit_controls.csv`，结果图为 `rocket_orbit_ga.png`。
`verify_orbit` 从最终状态关闭发动机，保留原重力和空气阻力，推进一个标称轨道周期，输出 `rocket_orbit_coast.mat/png`。
160 km 处仍有模型大气阻力，因此这里检验的是瞬时近圆入轨，不是永久保持圆轨道。

`rocket_orbit_ga` 和 `rocket_orbit_refine` 保留为连续燃烧、允许提前关机的另一种参数化；它们会覆盖通用轨道结果文件。
原始 `rocket_comet` 仍使用原来的 24 吨教学参数，不自动加载优化结果。

优化轨迹的动态尺度彗星图运行 `rocket_orbit_comet`：读取 `rocket_two_burn_result.mat`，
输出 `rocket_orbit_comet.gif`。左侧保留截至当前时刻的完整轨迹并逐步扩大视野，右侧跟踪最近 15 秒的运动范围；
两侧均采用等比例真实空间坐标，蓝色彗尾显示最近 25 秒，默认以 20 倍速播放。
脚本中的 `frameDt`、`playbackRate`、`tailSeconds`、`closeupSeconds` 可调整采样、播放速度与局部视野。

新版运行 `rocket_polar_comet`，输出 `rocket_polar_comet.gif` 和 `rocket_polar_comet.mp4`。
地心为极点、向右为零度、逆时针角度为正；主图显示极坐标网格，右图跟踪放大同一极坐标几何区域。
背景颜色按地心距离生成近地到深空的连续渐变，仅为示意，不代表真实大气光学模型。
读取两段燃烧优化状态后，独立积分发动机关闭后的一个完整标称轨道周期，仍包含空气阻力。
上升段以约 20 倍速播放，入轨后约 300 倍速，并在入轨时暂停展示；总模拟时长约 92.8 分钟。
灰色淡虚线是实时由位置速度计算的密切二体轨道，绘制前屏蔽地球内部段与非物理双曲线分支；
它忽略后续推力和阻力，因此不是对后续实际轨迹的承诺。初始近零角动量阶段的轨道退化，不绘制有效地外弧段。
