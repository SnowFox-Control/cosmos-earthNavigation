# 参数调整指南

## 火箭和目标轨道

修改 `config/rocket_orbit_config.m`：

| 参数 | 当前值 | 单位与含义 |
|---|---:|---|
| `p.m0` | 60000 | kg，起飞总质量 |
| `p.propellantFraction` | 0.98 | 推进剂占比，取0到1之间 |
| `p.mdry` | 自动计算 | `m0*(1-propellantFraction)`，无需另改 |
| `p.Isp` | `4500/9.80665`≈458.872 | s，比冲 |
| `p.c` | 自动计算 | `Isp*9.80665`，单位m/s |
| `opt.targetAltitude` | 500000 | m，离地高度，不是地心半径 |
| `opt.altitudeTolerance` | 500 | m，验收高度误差 |
| `opt.velocityTolerance` | 10 | m/s，径向和切向各自的验收误差 |

修改比冲时只改 `p.Isp` 的赋值，保留后面的 `p.c=p.Isp*9.80665`。
目标圆轨道速度自动按 `sqrt(mu/(Re+targetAltitude))` 计算。
修改后运行 `run_rocket('optimize')`，确认 `result.success` 后再运行 `run_rocket('animate')`。
新参数不一定存在可行轨道；到达高度不能代替速度条件。

该文件后半段的种群、代数、`opt.fractions` 和上下界供早期连续燃烧方案使用；
**当前两段燃烧的搜索设置以下面的配置为准。**

## 两段燃烧与粒子群优化（PSO）

修改 `config/rocket_two_burn_config.m`：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `opt.swarmSize` | 96 | 粒子数，至少8 |
| `opt.maxIterations` | 180 | 最大PSO迭代数，不含SQP |
| `opt.maxStallIterations` | 80 | 停滞迭代窗口 |
| `opt.functionTolerance` | 1e-10 | 停滞判断的目标变化容差 |
| `opt.inertiaRange` | `[0.1 1.1]` | 自适应惯性权重范围 |
| `opt.selfAdjustmentWeight` | 1.49 | 个体历史最优吸引权重 |
| `opt.socialAdjustmentWeight` | 1.49 | 邻域最优吸引权重 |
| `opt.minNeighborsFraction` | 0.25 | 最小邻域比例 |
| `opt.seed` | 161 | 随机种子，固定便于复现 |
| `opt.useLocalRefinement` | true | false时只运行PSO |
| `opt.heuristicFraction` | 0.5 | 启发初值占粒子群比例，0到1 |
| `opt.rampSeconds` | 0.5 | s，发动机启停流率过渡时间 |
| `opt.objectiveScale` | `[10000 1000 1000]` | 高度m、径向m/s、切向m/s的目标归一化尺度 |

目标函数为 `sum((误差./opt.objectiveScale).^2)`。尺度越小，该误差的权重越大；它不是验收容差。

`opt.lb` 和 `opt.ub` 是10个变量的下界与上界：

| 下标 | 变量 | 下界 | 上界 | 单位 |
|---|---|---:|---:|---|
| 1 | 第一段早期偏角 | 0 | 10 | 度 |
| 2 | 第一段中期偏角 | -10 | 10 | 度 |
| 3 | 第一段末期偏角 | -10 | 10 | 度 |
| 4 | 第二段起始偏角 | -10 | 10 | 度 |
| 5 | 第二段末期偏角 | -10 | 10 | 度 |
| 6 | 第一段平台流率 | 180 | 350 | kg/s |
| 7 | 第二段平台流率 | 120 | 350 | kg/s |
| 8 | 第一段燃烧时长 | 80 | 180 | s |
| 9 | 滑行时长 | 20 | 250 | s |
| 10 | 第二段燃烧时长 | 25 | 120 | s |

偏角是推力相对速度的角度，不是相对地面的俯仰角。搜索接口用度，ODE内部用弧度。
第二次点火时刻=`z(8)+z(9)`；最终关机时刻=`z(8)+z(9)+z(10)`。
提高流率/角度上界时，也要相应提高 `config/rocket_config.m` 中的 `p.qMax`、`p.deltaMax`。
第一段20%时长的转向节点必须晚于 `p.turnStart`；过渡时间必须足够短以保证时间节点顺序。

## 动画参数

修改 `config/rocket_visual_config.m`，然后直接 `run_rocket('animate')`，不用重新优化。

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `v.orbitPeriods` | 1 | 入轨后演示圈数，可取0.5、2等正数 |
| `v.frameRate` | 10 | 帧/秒 |
| `v.ascentStepSeconds` | 2 | 上升段每帧对应的模拟秒数 |
| `v.orbitStepSeconds` | 30 | 入轨后每帧对应的模拟秒数 |
| `v.ascentTailSeconds` | 30 | 上升段彗尾历史长度，s |
| `v.orbitTailSeconds` | 450 | 入轨后彗尾历史长度，s |
| `v.closeupInitialKm` | 12 | 起飞时局部视野宽度，km |
| `v.closeupFinalKm` | 242 | 入轨时及入轨后的局部视野宽度，km |
| `v.gradientScaleKm` | 160 | 渐变颜色衰减尺度，仅影响绘图 |
| `v.nearColor` | `[.18 .43 .57]` | 近地空间RGB颜色 |
| `v.deepColor` | `[.025 .04 .09]` | 深空/画布颜色 |
| `v.groundColor` | `[.055 .17 .20]` | 地球内部颜色 |
| `v.orbitColor` | `[.46 .52 .57]` | 瞬时轨道虚线颜色 |
| `v.showOsculatingOrbit` | true | 显示或隐藏虚线 |
| `v.writeGif` | true | 输出GIF，文件较大 |
| `v.writeMp4` | true | 输出MP4，推荐播放分享 |
| `v.outputPrefix` | `'rocket_polar'` | 输出文件名前缀，不含目录/扩展名 |

RGB分量范围0到1。**播放倍率=每帧模拟秒数×帧率**，当前为20倍和300倍。
将 `orbitStepSeconds` 从30改成15，会让入轨后播放慢一倍；增加 `orbitPeriods` 则延长模拟时间。
大气阻力始终保留，因此增加圈数会显示真实模型中的轨道衰减。
颜色渐变参数不控制大气阻力；实际密度由基础物理参数决定。

也支持不改文件的临时设置：

```matlab
startup
v = rocket_visual_config();
v.orbitPeriods = 2;
v.orbitStepSeconds = 15;
v.writeGif = false;
v.outputPrefix = 'rocket_two_orbits';
rocket_polar_comet(v);
```

## 基础模型与数值精度

修改 `config/rocket_config.m`：

| 参数 | 含义和单位 |
|---|---|
| `p.mu`、`p.Re` | 引力参数m³/s²、地球半径m |
| `p.rho0`、`p.H` | 海平面密度kg/m³、指数大气标高m |
| `p.Cd`、`p.A` | 阻力系数、迎风面积m² |
| `p.h0`、`p.theta0` | 初始高度m、初始极角rad |
| `p.u0`、`p.w0` | 初始径向/切向速度m/s |
| `p.turnStart` | 初始零偏角保持时长s |
| `p.qMax`、`p.deltaMax` | 流率上限kg/s、偏角幅值上限rad |
| `p.maxStep`、`p.relTol`、`p.absTol` | 基础求解器最大步长及误差容限 |

入轨的质量和比冲会被 `rocket_orbit_config` 覆盖。
该文件的原始 `control.t/delta/q` 仅控制24吨示例，不控制两段燃烧优化。
基础 `p.tf` 不决定优化的终点时间，优化以第二段关机为终点。
搜索/局部修正/终点复核为效率与精度分别设置积分容差，详见
`optimization/rocket_two_burn_pso.m` 中 `fast`、`precise`、`fine` 三段。

## 读取结果与重跑顺序

```matlab
startup
s = load(rocket_file('rocket_two_burn_result.mat'));
result = s.result;
result.success      % 入轨是否满足验收阈值
result.residual     % 高度m、径向m/s、切向m/s误差
result.z            % 最终10个设计变量
result.control      % 实际时间节点、偏角(rad)、流率
result.p            % 当次实际物理参数
result.opt          % 当次目标和搜索配置
```

改物理/目标/控制范围：`optimize` → 检查结果 → `animate`。
只改外观/播放速度/圈数：直接 `animate`。
配置改动不会自动重算MAT文件。动画读取MAT保存的实际参数，防止新参数与旧轨迹混用。
再次运行会覆盖同名输出，比较方案时先另存相关MAT、CSV或动画。

PSO主程序为 `rocket_two_burn_pso`；旧 `rocket_two_burn_ga` 名称会警告并转调PSO。纯PSO输出字段为 `result.psoX/psoFitness/psoResidual`，算法标记为 `result.optimizer`。已有GA结果仍保持原字段，不会自动重算或改名。


## 大气密度相关的高斯扰动

修改 `config/rocket_config.m` 中的 `p.noise`：

| 参数 | 默认值 | 含义 |
|---|---|---|
| `enabled` | true | 是否启用随机加速度 |
| `sigma0` | `[0.1 0.1]` | 参考密度下的径向、切向标准差，m/s² |
| `referenceDensity` | 1.225 | 参考大气密度，kg/m³ |
| `sampleInterval` | 1 | 高斯随机激励网格间隔，s；改变它会改变随机过程时间特征 |
| `seed` | 20261020 | 独立于PSO随机种子的扰动种子 |

实时扰动标准差为 `sigma0 * rho(h)/referenceDensity`。调小 `sigma0` 可减弱扰动，设 `enabled=false` 恢复确定性模型。起飞前 `p.turnStart` 秒固定径向推力，随后恢复相对速度方向的偏角控制。
修改扰动设置后需要重新优化；旧轨迹和动画不会自动变成含扰动的结果。保存数据的 `out.disturbanceAcceleration` 两列可查看径向/切向扰动历史。不同扰动种子对应不同飞行环境，当前优化并不自动对多个种子取平均。


## GPU与CPU并行

两段燃烧配置新增 `accelerationBackend='auto'`（可改为`'cpu'`或`'gpu'`）、`gpuStep=0.05`、`useParallel=true`、`parallelWorkers=4` 和 `parallelLocalRefinement=true`。
GPU阶段使用批量固定步长RK4近似，最终候选和局部修正使用CPU高精度ODE。GPU不支持时发出具体警告并回退CPU。

## MPC闭环控制

`run_rocket('mpc')` 加载成功的PSO轨迹，执行全状态跟踪，并在相同实际扰动下与开环对照。
参数在 `config/rocket_mpc_config.m`，可调整采样时间、预测步数、状态/控制权重、扰动种子、初始偏差和修正幅值。
完整公式、实测指标与限制见同目录 `GPU加速与MPC闭环控制.md`。


## 双火箭彗星动画（当前默认）

运行 `run_rocket('animate')`，读取 `rocket_mpc_result.mat` 中同一次试验的MPC与开环轨迹，白底同步展示两枚火箭。
参数位于 `config/rocket_comparison_visual_config.m`：`frameRate`、`ascentStepSeconds`、`coastStepSeconds` 控制播放倍率，`orbitPeriods` 控制关机后演示圈数，`ascentTailSeconds/coastTailSeconds` 控制彗尾时间长度。
`closeupMinimumKm/closeupMargin` 控制两枚火箭共用的局部放大视野，`writeGif/writeMp4` 控制导出格式。
上升段直接复用现有闭环与开环数据，不重跑控制器；关机后两枚火箭均按无推力动力学继续积分，不能把这段误解为持续施加MPC推力。
主图和局部图使用地心极坐标几何、等比例尺度，保留必要网格和地球表面线，不添加渐变或装饰。


双火箭动画新增两条实时密切轨道淡虚线：浅蓝对应MPC，浅红对应开环；绿色点划线表示目标圆轨道，并标注目标高度。
`rocket_comparison_visual_config.m` 中 `showOsculatingOrbits` 控制开关，`conicLightness` 控制向白色淡化的程度（越接近1越淡），`conicLineWidth` 控制线宽。
虚线从该帧的实际位置和速度计算，假设此后仅有地球中心引力，关闭推力、阻力和随机项；它是二次曲线参考，不是含大气条件下的实际后续轨迹。


圆轨化燃烧已使用独立动画采样：`circularizationStepSeconds=0.5`，默认10 fps下为5倍速；`transferStepSeconds=2` 为两段燃烧间滑行采样间隔。
时间轴明确包含第一段关机、第二次点火、圆轨燃烧中点和最终关机，不会由轨道滑行的大步长跨过第二段燃烧。
第二段显示 `BURN 2: CIRCULARIZATION` 与两枚火箭的实时流率；实心标记表示发动机工作，空心表示无推力。
第二次点火处暂停 `ignitionPauseSeconds=1` 秒，便于观察。所有改动仅影响动画采样和显示，不改动动力学或已保存控制轨迹。
